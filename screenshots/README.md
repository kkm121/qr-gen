# Screenshots (required by GDG task doc)

Save your captures here before pushing to GitHub:

| File | What to capture |
|---|---|
| `desktop.png` | Full desktop layout (1440px) with a generated QR |
| `mobile.png` | Mobile layout (375px) |
| `qr-types.png` | The 5 tabs (URL / Text / Email / Phone / Wi-Fi) |
| `customization.png` | Presets + size/colors/EC/margin controls |
| `download.png` | A downloaded PNG opened in an image viewer |

How to capture quickly:

1. `npm run dev`, open http://localhost:5173
2. DevTools (F12) → device toolbar → 375px for mobile shot, desktop for the rest.
3. Generate one QR per type and scan each with your phone before screenshotting.

> Delete this note file or keep it — the PNGs above are what reviewers look for.
